# Signal Engine V1 — locked behavior

## Admission
Pilot collector admits only the configured Westhampton Beach parcel universe. Parcel ID is the durable key.

## Evidence
A = official government record
B = transaction/listing evidence
C = secondary property data
P = proprietary CeeCee intelligence
? = conflicting/unverified

## V1 machine-created signals
- PROPERTY_STATE_CHANGE — an official parcel record differs from its prior snapshot.
- OWNER_RECORD_CHANGE — official owner table differs from its prior snapshot.

These are observations, not seller intent.

## Triage
- 0 independent active signal types: IGNORE
- 1: WATCH
- 2 or more: INVESTIGATE
This is an initial workload-control rule, not a predictive score. It will be replaced/refined from observed outcomes.

## Hard governor
No outreach is authorized by an INVESTIGATE state alone.
A separate compliance/contact governor must establish a legitimate WHY NOW before contact.

## Next adapters
Assessment snapshot; zoning/context; deed/title event history; market/listing history; CeeCee legacy intelligence; genuine buyer-demand matches.
