# V16P — Multi-Evidence Candidate Context

Read-only cross-check of the V16O current-event review population against independent evidence families already held in the persistent PMI evidence ledger.

It profiles property context, assessment context, current ownership evidence, and transfer/title evidence without emitting owner names or addresses. Multiple owner rows are treated only as factual source complexity. No seller intent, scoring, INVESTIGATE mutation, contact authorization, outreach, or database writes.

Endpoint: `/api/intelligence/multi-evidence-candidate-context-v16p`

Protected prerequisites: V16K1, V16L1, V16M, V16N, V16O.
